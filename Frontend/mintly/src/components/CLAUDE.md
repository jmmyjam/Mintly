# Frontend components — `Frontend/mintly/src/components/`

Shared UI, one file per component. Reuse these instead of re-inlining their markup in pages; new reusable UI goes here, not inline in a page file. Global rules: repo-root `CLAUDE.md`; frontend-wide commands, `api.ts`, shared non-component modules (`hooks.ts`, `accessibility.ts`, `format.ts`, `affiliate.ts`, `variants.ts`), styling, conventions, gotchas: `Frontend/mintly/CLAUDE.md`; the pages that consume these: `src/pages/CLAUDE.md`.

- **Navbar** — favicon leaf logo + wordmark left, the Search/Portfolio nav pill screen-centered (3-column grid), profile avatar (→ `/profile`) or `Login` link right; auto-hides on scroll-down past 80px and reappears on any upward scroll (`navbar-hidden` toggled by a scroll listener; honors reduce-motion). Its compaction breakpoints (`Navbar.module.css`) are the app's one deliberate media query.
- **Footer** — brand, quick links incl. the external Buy Me a Coffee donation link (`https://buymeacoffee.com/mintlytcg`), the Pokemon/TCGplayer/eBay trademark + affiliate-links disclaimer, "prices are informational only" note, © line. Renders on every page on the outer frame below the content panel.
- **HeroSearch** — the Home hero search pill: typewriter placeholder cycling example queries (honors reduce-motion), quick-search chips, navigates to `/search?q=`.
- **PriceQtyForm** — the price+quantity form behind Search's inline add, CardDetail's labeled add, and Portfolio's lot editor — props switch labels, button size, busy state, optional Cancel.
- **StatRow** — label/value `price-row` line. **GainLoss** — signed, colored dollar amount with optional percent. **DayChange** — compact daily price-change chip (arrow + amount + percent, green/red/muted); on search tiles, CardDetail, and Portfolio.
- **PriceHistoryChart** — per-card recharts chart from `/cards/{id}/history`, with 1M/6M/1Y/All range buttons that filter the fetched series client-side — remount per card with `key={cardId}` so `loading` resets without a synchronous `setState` in the effect; takes an optional `currentPrice` and overlays it onto today's point via `useMemo` so the line always ends on the live price shown above it (closing the gap when a background price refresh lands after the chart already loaded). Two render modes: a single-variant card keeps the mint area chart of the headline series; a card with 2+ variant series gets one 2px line per variant — fixed color per variant *name* from `variants.ts`, a swatch legend, a short direct label at each line's end (identity never rides on color alone), per-variant `currentVariantPrices` overlays, `connectNulls` across gapped days, and a lone dot for a series with only one point yet. The headline series is merged into the preferred variant's line via `mergeHeadline`, so pre-variant history isn't lost; `onData` reports the fetched `CardHistory` up to CardDetail for the variants table.
- **CardImage** — the single element for all card artwork — search/portfolio tiles pass `size="tile"`, the card-detail hero passes `size="detail" eager`; reserves the 5:7 card ratio so the grid never shifts as images load, and swaps to a muted "image unavailable" placeholder (with `role="img"` + the card name) when the src is missing, the load fails, or the loaded file is upstream's 404 card-back PNG, detected by its fixed 640×892 natural size since a decodable 404 body never fires `onError`. Use it for every card image, never a raw `<img>`.
- **CameraViewfinder** — the `/scan` scanner's capture UI: a live rear-camera `<video>` (`getUserMedia` at up to 1080p; `playsInline`/`muted`/`autoPlay` for iOS; tracks stopped on unmount) inside a 5:7 card-outline frame. `capture()` maps the on-screen frame back into native video pixels (accounting for `object-fit: cover`) and passes a cropped canvas to `onCapture`; falls back to a file-input ("choose a photo") when the camera is denied/unsupported/desktop. Has its own module CSS.
- **PageMessage** — centered full-page loading/error/logged-out state with optional CTA link. **NotFoundMessage** — the one "Page not found" view, rendered by the `NotFound` catch-all page and by Admin's denied states, so a guessed `/admin` is byte-identical to `/taco`. **StatusMessage** — inline success/error status line (the post-add message in Search/CardDetail and Portfolio's lot edit/remove errors).
- **SignedOutHero** — the promotional hero shown to logged-out visitors in place of the plain login prompt on the account-only pages: `variant="scan"` (Portfolio, `variant="portfolio"`) sell the feature with a mint-accented card (eyebrow / big headline / copy / two badge pills) beside a decorative visual — the scan variant reuses the Home `/scan` viewfinder frame (Pikachu-ex card + mint corner brackets), the portfolio variant the Home hero's fanned SIR trio (`sv3pt5/200,199,198`) — plus a cream **Log in** CTA and a "Create a free account" link that carries `state={{ register: true }}` so `Login` opens on the Register tab. Has its own CSS module (mirrors Home's `scan-section`/hero-card styling), so it's not one of the module-less shared presentational components below.
- **StructuredData** — renders a JSON-LD `<script type="application/ld+json">` block (Google reads them from the body, so pages mount them inline; `<` is escaped so external strings can't close the tag early). Site-wide Organization/WebSite/WebApplication graph in `App.tsx`, per-card Product markup in CardDetail.
- **DeleteAccount** — the Profile "danger zone": two-step, typed-"DELETE" confirm, calls `deleteAccount()`, then routes to `/login` with a notice via `useSessionRedirect`'s sibling flow.

The shared presentational components (`DayChange`, `GainLoss`, `StatRow`, `StatusMessage`, `PriceQtyForm`, `PageMessage`) intentionally have **no** CSS module — their classes are part of the global shared vocabulary in `App.css`.
