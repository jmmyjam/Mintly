# Frontend components — `Frontend/mintly/src/components/`

Shared UI, one file per component. Reuse these instead of re-inlining their markup in pages; new reusable UI goes here, not inline in a page file. Global rules: repo-root `CLAUDE.md`; frontend-wide commands, `api.ts`, shared non-component modules (`hooks.ts`, `accessibility.ts`, `format.ts`, `affiliate.ts`, `variants.ts`), styling, conventions, gotchas: `Frontend/mintly/CLAUDE.md`; the pages that consume these: `src/pages/CLAUDE.md`.

- **Navbar** — favicon leaf logo + wordmark left, the Search/Scan/Portfolio nav pill screen-centered (3-column grid), and a right slot that is the profile avatar (→ `/profile`) when signed in, or a "Log in" text link + a cream "Sign up" pill (→ `/login` with `state={{ register: true }}`) when signed out; auto-hides on scroll-down past 80px and reappears on any upward scroll (`navbar-hidden` toggled by a scroll listener; honors reduce-motion). Its compaction breakpoints (`Navbar.module.css`) are the app's one deliberate media query: ≤768 shrinks everything, ≤460 hides the wordmark and switches the row from the rigid 1fr/auto/1fr grid to flex (so the leaf doesn't reserve as much room as the two auth items, which would clip "Sign up"), ≤374 drops the "Log in" link, ≤340 is the final tighten.
- **Footer** — brand, quick links incl. the external Buy Me a Coffee donation link (`https://buymeacoffee.com/mintlytcg`), the Pokemon/TCGplayer/eBay trademark + affiliate-links disclaimer, "prices are informational only" note, © line. Renders on every page on the outer frame below the content panel.
- **HeroSearch** — the Home hero search pill (styled like `/search`: glyph + input + cream Search button): a typewriter placeholder cycling `EXAMPLES` (honors reduce-motion → static fallback), rendered as a **mint-caret overlay** (an `aria-hidden` span with a `--accent` right border, shown only while the field is empty and unfocused, so the real input keeps a static `aria-label`), and a "Try" chip row (`QUICK_SEARCHES` incl. Umbreon; wraps on desktop, scrolls horizontally on mobile). All chips + submit navigate to `/search?q=`. The typewriter hook is untouched from before.
- **PriceQtyForm** — the price+quantity form behind Search's inline add, CardDetail's labeled add, and Portfolio's lot editor — props switch labels, button size, busy state, optional Cancel.
- **StatRow** — label/value `price-row` line. **GainLoss** — signed, colored dollar amount (minus-before-dollar via `signedMoney`, tabular via `.num`) with optional percent. **DayChange** — compact daily price-change chip (arrow + amount + percent, green/red/muted); on search tiles, CardDetail, Portfolio, and the Holding page. An optional `today` flag appends the word "today" after the figure (the portfolio grid tile + the holding position panel's "Your value" line).
- **PriceHistoryChart** — per-card recharts chart from `/cards/{id}/history`, with 1M/6M/1Y/All range buttons that filter the fetched series client-side — remount per card with `key={cardId}` so `loading` resets without a synchronous `setState` in the effect; takes an optional `currentPrice` and overlays it onto today's point via `useMemo` so the line always ends on the live price shown above it (closing the gap when a background price refresh lands after the chart already loaded). Two render modes: a single-variant card keeps the mint area chart of the headline series; a card with 2+ variant series gets one 2px line per variant — fixed color per variant *name* from `variants.ts`, a swatch legend, a short direct label at each line's end (identity never rides on color alone), per-variant `currentVariantPrices` overlays, `connectNulls` across gapped days, and a lone dot for a series with only one point yet. The headline series is merged into the preferred variant's line via `mergeHeadline`, so pre-variant history isn't lost; `onData` reports the fetched `CardHistory` up to CardDetail for the variants table. **Opt-in props for the Holding route** (all default off, so CardDetail is byte-for-byte unchanged): `title` overrides the "Price History" heading; `segmentedRange` swaps the range buttons for the shared cream `.segmented` control; `avgCost` draws a dashed `--negative` `ReferenceLine` with a right-edge "your avg $…" pill (custom SVG label anchored to the line's plotted viewBox); `purchases` (a `PurchaseMarker[]` of `{date, price}`) draws cream-ringed `ReferenceDot`s snapped to the nearest tracked day; the overlays use `ifOverflow="extendDomain"` so the axis grows to include them, add a bottom legend (Market price · Your purchases · Your average cost), and give the panel the larger `--radius-lg`.
- **CardImage** — the single element for all card artwork — search/portfolio tiles pass `size="tile"`, the card-detail hero passes `size="detail" eager`; reserves the 5:7 card ratio so the grid never shifts as images load, and swaps to a muted "image unavailable" placeholder (with `role="img"` + the card name) when the src is missing, the load fails, or the loaded file is upstream's 404 card-back PNG, detected by its fixed 640×892 natural size since a decodable 404 body never fires `onError`. Use it for every card image, never a raw `<img>`.
- **CandidatePickerModal** — the scanner batch-mode override "popup" (the app's only modal): a dimmed fixed overlay showing a queued scan's ranked candidates as a tappable grid; picking one sets that queue item's selection, plus a "Rescan this card" action (drops it from the batch) and Close (backdrop click / Esc / button). Kept minimal, inside the design tokens; has its own module CSS.
- **CameraViewfinder** — the `/scan` scanner's capture UI: a live rear-camera `<video>` (`getUserMedia` at up to 1080p; `playsInline`/`muted`/`autoPlay` for iOS; tracks stopped on unmount) inside a 3:4 viewport with an accent **corner-bracket** guide over a 5:7 card crop region (`frameRef`, dimmed outside by a huge box-shadow mask), a top-left status chip ("Camera live" / amber "Finding your card…" while `busy`) and a bottom hint pill. `capture()` maps that crop region back into native video pixels (accounting for `object-fit: cover`) and passes a cropped canvas to `onCapture`. Below the frame: a full-width cream **Capture** pill ("Scanning…" + disabled while `busy`) and a subtle "or choose a photo" file fallback. When the camera is denied/unsupported/desktop it shows the error message in the frame's footprint with "Choose a photo" plus an optional "Search by name instead" button (`onSearchByName` prop). Has its own module CSS. Used only by `Scan.tsx` (single + batch).
- **PageMessage** — centered full-page loading/error/logged-out state with optional CTA link. **NotFoundMessage** — the one "Page not found" view, rendered by the `NotFound` catch-all page and by Admin's denied states, so a guessed `/admin` is byte-identical to `/taco`. **StatusMessage** — inline success/error status line (the post-add message in Search/CardDetail and Portfolio's lot edit/remove errors).
- **SignedOutHero** — the promotional surface shown to logged-out visitors in place of the plain login prompt on the account-only pages (11c/11d redesign). Two divergent layouts that sit directly on the main panel (no bordered card), sharing an `AuthActions` CTA row (a primary pill + a "Create a free account" link carrying `state={{ register: true }}` so `Login` opens on the Register tab). **`variant="portfolio"`** (Portfolio): "the gate shows what it's gating" — a full-bleed 6-up grid of blurred, scrimmed real card art (`getCardImageUrl`, art only, no numbers/prices) behind a pitch (eyebrow / big headline / copy / two mint badge pills / cream **Log in**) pulled up over it, with the Home hero's fanned SIR trio (`sv3pt5/200,199,198`) on the right; below 860px the fan drops and below 720px the whole blurred backdrop + scrim drop (avoids blurring big images on phones). **`variant="scan"`** (Scan): copy with a numbered **three-step** how-it-works (Frame → Confirm → Queue) and a **mint** "Log in to scan" CTA (matching the scan flow's own primary), beside a dead viewfinder — a striped "Camera off" panel with a mint camera glyph inside the mint corner-bracket frame — collapsing to one column below 860px. Has its own CSS module, so it's not one of the module-less shared presentational components below.
- **StructuredData** — renders a JSON-LD `<script type="application/ld+json">` block (Google reads them from the body, so pages mount them inline; `<` is escaped so external strings can't close the tag early). Site-wide Organization/WebSite/WebApplication graph in `App.tsx`, per-card Product markup in CardDetail.
- **DeleteAccount** — the Profile "danger zone": two-step, typed-"DELETE" confirm, calls `deleteAccount()`, then routes to `/login` with a notice via `useSessionRedirect`'s sibling flow.

The shared presentational components (`DayChange`, `GainLoss`, `StatRow`, `StatusMessage`, `PriceQtyForm`, `PageMessage`) intentionally have **no** CSS module — their classes are part of the global shared vocabulary in `App.css`.
